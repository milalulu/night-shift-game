# Нативная версия «Смены 13»

Это отдельный проект на **Godot 4**. Он запускается как обычное desktop-приложение: браузер, сайт и хостинг для игры не нужны. Веб-версия из корня репозитория пока остаётся демо.

## Запуск в Linux

Нужен Godot 4.7 или новее:

```bash
./run.sh
```

Либо открой папку `native/` в редакторе Godot и запусти `scenes/main.tscn`.

## Управление

- **WASD** — движение; мышь — осмотр
- **Shift** — бег; **Ctrl** — красться
- **E** — действие / закрыть документ
- **F** — фонарь; **Esc** — пауза; **R** — центрировать взгляд

В нативном проекте сейчас доступны **оба эпизода**:

- **Эпизод I — «Линия четыре»:** узел связи, поиск трёх предохранителей, генератор, мастер-лента, код 3–7–2 и три финала.
- **Эпизод II — «Белый шум»:** районный радиоцентр, три катушки, резервный генератор, код 5–1–9 и ветвящийся финал.

Решение из первого эпизода меняет вступление второго. Чувствительность мыши и инверсия X настраиваются в меню паузы; поворот камеры ограничен по скорости и обрабатывается Godot напрямую. Прогресс хранится в отдельных файлах для каждого эпизода: `user://shift13_episode1.cfg` и `user://shift13_episode2.cfg`. Старый единый файл мигрируется автоматически.

## План нативной версии

1. Проверить связное прохождение двух эпизодов, сохранения и баланс финалов.
2. Добавить постановочные сцены, актёрскую озвучку и более умное поведение существа.
3. Перенести третий эпизод «Голос», затем подготовить Linux/Windows-сборки.

Русские реплики-плейсхолдеры лежат в `audio/`. Их позже можно заменить актёрской озвучкой без изменений игрового кода.
