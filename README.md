# Смена 13 — Узел связи

Небольшой атмосферный 3D-хоррор от первого лица, созданный с нуля на Three.js.

## Играть онлайн

Проект готов для GitHub Pages и автоматически публикуется при каждом push в ветку `main`.

1. Создай GitHub-репозиторий и загрузи в него содержимое этой папки в ветку `main`.
2. В репозитории открой **Settings → Pages** и выбери **GitHub Actions** как источник публикации.
3. Дождись завершения workflow **Deploy game to GitHub Pages** во вкладке **Actions**.

После этого GitHub покажет ссылку на игру в настройках Pages. Хостинг и сервер настраивать отдельно не нужно. Для запуска страницы потребуется интернет: Three.js и шрифты загружаются с CDN.

## Запуск локально

Открой `index.html` в браузере с доступом в интернет: Three.js загружается с jsDelivr. Если браузер запрещает ES-модули при открытии файла напрямую, запусти локальный сервер из этой папки:

```bash
python3 -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Управление

- **WASD** — движение, **мышь** — осмотр
- **Shift** — бег
- **E** — взаимодействие / чтение записки
- **F** — фонарь
- **Esc** — пауза

## Этапы

1. **Основа:** игровая сцена, управление от первого лица, атмосферный свет и интерфейс.
2. **Игровой цикл:** найти три предохранителя, прочитать подсказку, запустить генератор и открыть выход.
3. **Атмосфера:** преследователь, фонарь, рация, звуковой гул, экранные эффекты и финал.
